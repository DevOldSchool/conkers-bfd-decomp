# Source boundaries

[Evidence index](../README.md) · [Documentation](../../README.md)

Boundary records explain why functions and sections belong together. They do
not establish matching C or current integration state; those belong to the
[source-unit inventory](../../../progress/source_units.json).

| Area | Records |
| --- | --- |
| [Game overlay](game/README.md) | Structural families, mappings and registration history |
| [Main executable](main/README.md) | Main families, residual frontier and regional comparisons |
| [Named effects](effects/README.md) | Blood, light, framebuffer, pipe and flamethrower families |

[Library objects](../libraries/README.md) and
[data/section layout](../data-layout/README.md) have separate indexes.
