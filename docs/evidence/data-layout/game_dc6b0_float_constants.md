# US game_DC6B0 particle float constants

`func_150B0094` fills a particle packet and stores the same per-function rodata constant `D_8009F7D8` into two packet fields (`packet.field8 = packet.fieldC`).

With the extern symbol IDO allocates the value differently (CURRENT 75); the `0.7f` literal reproduces the raw function (CURRENT 0). The checksum-validated US game-data archive contains big-endian `3F333333` (0.7) at 0x8009F7D8. ROM SHA1 is `4cbadd3c4e0729dec46af64ad018050eada4f47a`; game-data base 0x80082B20.

`func_150AF328` advances an emitter counter and spawns smoke sprites. Its raw HI16/LO16 pairs in `asm/nonmatchings/game_DC6B0/func_150AF328.s` address six consecutive words at 0x8009F7B8..0x8009F7CF; no other reference function touches them. The archive holds `44D44000 38D1B717 3F7870B9 3F82B114 3DC8B43A 3E3020C5` there, exactly `1698.0f`, `0.0001f`, `0.97047f`, `1.021029f`, `0.098000005f` and `0.172f` in load order (the same values as the sibling `func_150EC6B0`, [record](game_1199d0_float_constants.md)). With externs the deferred body scored CURRENT 2136; with the literals the function is CURRENT (0).

The two pools are not adjacent: 0x8009F7D0/0x8009F7D4 hold `40490FDB` (3.1415927) and `3E89374C` (0.268), still read through externs by the matched `func_150AF7C4`, and 0x8009F7DC onward are externs of `func_150B0348`. The generated `game_DC6B0.o` has rodata `44d44000 38d1b717 3f7870b9 3f82b114 3dc8b43a 3e3020c5 3f333333 00000000`: the six `func_150AF328` constants, the `0.7f` constant and 4 zero alignment bytes (0x20 in all), with no data relocations. A single mapping would place `0.7f` over the ROM's 3.1415927 at 0x8009F7D0, so game_DC6B0 is a split unit: `scripts/split_game_rodata.py` splits it into `.rodata.dc6b0_0` (0x18 at 0x8009F7B8) and `.rodata.dc6b0_18` (0x4 at 0x8009F7D8), each with an exact linker size assertion, as described in [game rodata literal sub-pools](game_rodata_literal_sub_pools.md). `config/data/us.json` records both owners.

The INFO mapping retains linked bytes for verification without appending to the code-only payload; `scripts/verify_game_rodata.py` compares both sections with ROM. No reference assembly, compiler flag or verifier changes are involved.
