## Native consumers

`func_15080828` selects bank `1A`, language `D_800BEAAB` and a dialogue ID
through the depth-three `func_1502B6BC` loader. It can additionally select ID
`43` as a prefix. The generic loader resolves eight-byte offset/size/flag
records; `1502B4A8` counts to the high-bit final-record marker, retains the
low 28 size bits and relocates each nonempty offset.

Each dialogue payload is a two-record directory: NUL-terminated text first,
then 16-bit audio IDs. `15080828` reads the second size and divides it by two;
`15080784` indexes those unsigned halfwords and sends each nonzero ID to
`1001263C`. A zero ID remains a meaningful silent queue entry. The 18 payloads
contain 57 IDs in total.

The loader passes the text to `1516A7B0`. Its supplied-text path calls
`1516A770`, which replaces each `BD` byte with a NUL and counts pages.
`1516C878` walks the resulting strings. The text has 67 pages in total.
`1516C934` passes each line to the renderer `150417AC`; the measurement routine
`150428D4` handles byte `0A` as a newline. Ordinary character lookup uses
`15042C40` and the 95-byte map at `80085930`, preserving source case.

The checked 27-entry dispatch at `80098B14`, indexed by code minus `A1`, proves

## Encoding and scope

`build/assets/asset-directories/us/bank1A/dialogue/` contains a manifest and
`dialogue.json`. Sources contain typed language-directory fields, pages of
text/control segments and unsigned audio IDs. There is no raw-byte escape.
Page separators and the final NUL are generated. The text child ends at the
minimum halfword boundary; the audio child and the container end use minimum
eight-byte alignment. All 18 records satisfy these fixed packing rules with
zero alignment bytes. Extra padding or nonzero alignment is rejected rather
than preserved as an opaque source field.

Five payloads use raw DEFLATE level six with a big-endian decoded-length
prefix. Fresh encoding and compression reproduce their original stored bytes;
the other 13 payloads are uncompressed. The 15 bytes between physical payloads
are not part of these container rules and remain excluded.

The builder preserves the existing parent directory, manifest and backing.
Edits, missing files and source races fail without overwriting inputs. Explicit
`./conker asset-directories recover --part bank1A` backs up the entire parent
before restoring reviewed inputs. Make tracks edits and deletions in the child.

The report compares all 23 new ranges with the independent ROM and the complete
actual linked `asset_bank_1a.o`. A change anywhere in that linked object,
including uncredited backing, fails validation. The outer directory and other
families retain separate, disjoint credit.
