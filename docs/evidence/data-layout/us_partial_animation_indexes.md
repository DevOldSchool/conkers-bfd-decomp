# US indexes within partially reconstructed animation containers

Four bank-02 containers have understood nested directory records even though
each contains an unresolved animation clip. This change reconstructs only those
242 eight-byte directory records (1,936 bytes), alongside the previously
accepted 117 clips. It does not claim the four whole containers are understood.

The native paired-segment contract is the same one checked by
`model_animation_build.animation_segments` and the existing full-consumer
guards in `animation_clips_build.reviewed_objects`. Each record has a relative
offset, stored byte length and flag nibble. The first offset establishes the
directory extent, the segments are contiguous and aligned, and only the last
record has the final flag. The segment count is twice the reviewed pair count.
Every directory lies wholly inside its reviewed container and is disjoint from
all previously credited asset ranges. Existing clip duration and tail checks
remain intact.

`scripts/animation_index_inputs.py` uses the strict typed directory codec.
Each existing object gains `indexes/manifest.json` and `indexes/indexes.json`
under its `build/assets/animation-clips/us` input directory. The accepted parent
manifest, clips and backing file stay unchanged. Packing regenerates the indexes
from their typed fields, verifies their exact extents and hashes, and overlays
them with the already reconstructed clips. Unexplained payload bytes remain
backing storage and receive no credit. Missing or changed child inputs fail
without replacement; explicit recovery backs up the complete input directory.

The actual three linker objects keep their existing paths and exact bytes.
Make tracks both child files and their encoder. The report verifies the current
inputs and linked objects, then includes only the sorted, disjoint fresh index
and clip ranges. Rebuilt coverage rises from 219,664 to 221,600 bytes. The remaining 46,632 bytes in those objects stay raw.

source fields; all 726 field mutations change bytes or fail. The actual three

ranges. Bank-02 unmatched storage falls from 48,568 to 46,632 bytes.
